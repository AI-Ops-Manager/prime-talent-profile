## 個人情報

- [ ] 氏名が全箇所でイニシャル（ヘッダー・氏名欄・フッターの近く・`_note` 以外の本文）
- [ ] 連絡先・SNS・ポートフォリオ URL・本人の面談予約リンクが無い
- [ ] 現職・自社の社名が業種表現になっている。役員・代表なら公開プロダクト名も
- [ ] 写真: 出す運用なら表示されている。伏せる運用ならイニシャルの枠になっている
- [ ] `npm run check -- <slug>` が警告なし

## 内容

- [ ] 数字・実績がデータの記載どおり（丸めていない、足していない）
- [ ] 肩書きと本文の表現が `devSkillLevel` / `aiSkillLevel` に見合っている
- [ ] 稼働目安・稼働開始が最新の確認内容と一致している（食い違いは `_note` に残した）
- [ ] 単価の表示が取り決めどおり（既定表示のまま、または案件の個別値）
- [ ] 「希望領域」が打診先の文脈に寄っている（汎用なら本人の志向）
- [ ] 概要が2段落、太字が各段落1箇所以内

## 体裁

- [ ] `npm run render` にはみ出し警告が出ていない
- [ ] ページ数がフッター表記（01 / 03 等）と一致
- [ ] 各ページで本文がフッターに重なっていない
- [ ] ヘッダーのロゴ・名義が正しい会社のもの（他社の名義で出していない）
- [ ] 語の途中で不自然に改行している見出しが無い
- [ ] 「——」「まさに」「圧倒的」「一気通貫」「〜を実現」が残っていない
